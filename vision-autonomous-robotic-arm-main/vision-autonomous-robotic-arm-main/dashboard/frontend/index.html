Digital Twin & Simulation Pipeline

How the Digital Twin Synchronizes:
1. Live Gazebo GUI: the real Gazebo window is rendered into Xvfb and streamed via x11vnc + noVNC (port 6080) — orbit, zoom and interact directly with the simulated world.
2. Three.js URDF Twin: /robot_description is loaded with urdf-loader and driven by live /joint_states from Gazebo (rosbridge :9090).
3. Bi-Directional Control: joint sliders, gripper and pick buttons publish trajectory goals back into the simulator; gamepad input can be bridged from the browser to /joy for PS5/Xbox/F710 teleop.
4. Safe Motion Validation: the twin can preview trajectories in simulation before executing on the physical arm.

Cartesian Inverse Kinematics (IK) Teleoperation Architecture (Phase C)

How Teleoperation Demonstration Collection Will Work:
1. Left Stick (X / Y): Moves the end-effector in Cartesian table space (centimeters relative to base).
2. R2 / L2 Triggers: Controls end-effector Z-height (raise / lower arm towards table).
3. Right Stick & R1/L1: Controls Wrist Pitch/Roll orientation and Gripper open/close state.
4. Python IK Engine (`ik_solver.py`): Receives the target $(X, Y, Z, \theta_{pitch}, \theta_{roll})$ from the PS5 controller, calculates exact joint angles $(\theta_1, \theta_2, \theta_3, \theta_4, \theta_5, \theta_6)$, and streams them at 30Hz to the Arduino.
This Cartesian control pipeline ensures human operators record smooth, high-quality trajectories for imitation learning.
